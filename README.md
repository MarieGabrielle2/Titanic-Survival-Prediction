# Titanic-Survival-Prediction (Machine Learning)
This repository contains a Machine Learning project built using Python and Jupyter Notebook to predict passenger survival on the Titanic dataset.
## Project Overview
The goal of this project is to binary-classify whether a passengerd survived the titanic disaster based on features like age, gender, passenger class, familysize, ticket fare, etc...
## Performance and Results
- Project type: Binary Classification
-Best Model: Used a Machine Learning pipeline to evaluate model performance.
-Best Kaggle Score: 0.79186( Top leaderboard standard for foundational Kaggle projects).
- Platform: Kaggle
## Technologies & Libraries
- Programming Language: Python
- Devellopement Environment: Jupyter Notebook
- Data Manipulation: Pandas, Numpy
- Data Visualization: Matplotlib, seaborn
- Machine Learning: Scikit-Learn, XGBoost
- Model Evaluation: Accuracy, Precision, Recall, F1-Score, Cross-Validation
## Machine Learning Workflow
1. Data Loading & Exploratory Data Analysis(EDA)
2. Data Cleaning & Preprocessing
3. Feature Enginnering
4. Model Training & Selection
5. Model Evaluation & Optimization
6. Final Prediction & Kaggle Submission
